SLAM Phylogeny

Codex context-aware semantic curation

References는 citation context를 읽고 매칭했다

지금 사이트의 Matched Handbook references는 단순 keyword/regex 매칭이 아닙니다. SLAM Handbook 본문에서 각 reference가 실제로 인용된 장, 절, 주변 문장을 추출한 뒤, 그 문맥에서 그 논문이 어떤 역할로 호출됐는지를 기준으로 primary taxonomy path를 배정했습니다.

즉 title만 보는 것이 아니라, 예를 들어 같은 feature 논문이라도 Visual SLAM 장에서 인용됐는지, Place Recognition 절에서 인용됐는지, Learning 장에서 인용됐는지에 따라 다르게 배정합니다.

Current pipeline

  1. scripts/build_reference_dataset.py로 PDF References의 [1]부터 [1320]까지 파싱합니다.
  2. scripts/enrich_reference_contexts.py로 본문 citation 주변 문장과 chapter/section을 추출합니다.
  3. scripts/codex_context_semantic_match.py가 내가 정한 SLAM taxonomy 역할 기준을 적용합니다.
  4. reference마다 가장 의미가 강한 citation context를 보고 Phylum > Class > Order 하나를 먼저 고릅니다.
  5. scripts/assign_genus_labels.py가 해당 Order 아래의 Genus 후보 중 title, citation entry, rationale, Handbook context와 가장 잘 맞는 Genus를 고릅니다.
  6. 결과를 confidence, rationale과 함께 data/references_semantic.js에 저장하고 사이트가 이 파일을 우선 사용합니다.
python scripts/build_reference_dataset.py
python scripts/enrich_reference_contexts.py
python scripts/codex_context_semantic_match.py
python scripts/assign_genus_labels.py
지금 출력은 단일 label이 아니라 matched_paths[]를 같이 저장합니다. 즉 한 논문이 대표 path와 별개로 sensor family, front-end, map representation, evaluation 같은 여러 역할에 동시 참여할 수 있습니다. Regex로 하나를 찍는 구조가 아니라, Handbook citation context와 논문 title/entry의 역할을 보고 primary/secondary semantic membership을 구분합니다.

Decision principle

  • sensor-specific full system이면 Sensor & Odometry Modalities.
  • feature, registration, odometry, place recognition, loop closure, data association이면 Measurement Front-End.
  • solver, factor graph inference, robust objective, certifiable method이면 Back-End Optimization & Inference.
  • world representation이면 Map Representations.
  • manifold, Lie group, uncertainty, observability, factor graph modeling이면 State, Geometry & Probabilistic Modeling.
  • learning 자체가 핵심 novelty일 때만 Learning, Semantics & Spatial AI.
  • title만으로 애매하면 Handbook citation context의 chapter/section/excerpt를 우선합니다.

Outputs

  • data/slam_handbook_references_semantic.csv: 현재 사이트가 쓰는 semantic curation CSV
  • data/slam_handbook_references_semantic.json: full semantic curation JSON
  • data/slam_handbook_references_with_contexts.json: reference + citation contexts
  • scripts/codex_context_semantic_match.py: 현재 curation logic
  • scripts/assign_genus_labels.py: Order-level labels를 Genus-level labels로 세분화하는 script
  • scripts/semantic_match_references.py: 외부 frontier API로 재검토할 때 쓸 batch matcher
현재 반영된 결과: 1320개 reference 전체가 Phylum > Class > Order > Genus까지 매칭됨. 1318개에 citation context 사용, 총 2473개 citation context 추출.
이 결과는 내가 Handbook context와 taxonomy 역할 기준을 보고 만든 1차 semantic curation입니다. 다음 교정 단계에서는 confidence가 낮거나 rationale이 약한 항목부터 사람이 확인하면 됩니다.
